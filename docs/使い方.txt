AC6 Stamp - 使い方
====================

ARMORED CORE VI の対戦録画から、対戦開始のタイムスタンプと対戦相手の名前を読み取り、
YouTube のコメント欄に貼れる一覧を作るツールです。

■ 最初に一度だけ：ffmpeg を入れる
録画を読むために ffmpeg が必要です。ライセンスの都合で同梱していません。
コマンドプロンプトを開き、次を実行してください。

    winget install Gyan.FFmpeg

入れたあとは、コマンドプロンプトを開き直してから起動してください。
手で入れる場合は https://www.gyan.dev/ffmpeg/builds/ から ffmpeg.exe を取り出し、
AC6Stamp.exe と同じフォルダに置いても動きます。

■ 基本の使い方
1. AC6Stamp.exe を起動します。
2. 録画ファイルをウィンドウにドラッグ&ドロップし、「解析開始」を押します。
3. 終わったら「コピー」を押して、YouTube のコメント欄に貼り付けます。
   録画と同じフォルダにも「〜_対戦リスト.txt」が保存されます。

※「自分のパイロット名」を入れておくと、相手の名前だけが一覧に出ます。
  空欄でも、3試合以上あれば自動で判定します。

■ OBS との連携（録画停止で自動解析）
1. OBS の「ツール」→「スクリプト」を開き、「＋」で ac6stamp_obs.lua を追加します。
2. 「AC6Stamp.exe の場所」に、この AC6Stamp.exe を指定します。
3. 録画を停止すると、AC6 Stamp が起動して解析を始めます。

※ このフォルダごと移動した場合は、2. の場所を指定し直してください。

■ うまく読めないとき
・「読み取り位置の調整…」で録画の1コマを表示し、正しく読めるか確認できます。
  「次の対戦開始画面を探す」を押すと、UNIT ALPHA / BETA の画面まで自動で進みます。
・自動で読めない場合は「手動で位置を指定」に切り替え、ラベル（UNIT ○○）と
  名前欄をマウスで囲んで「保存して閉じる」を押してください。
・位置を変えたあとは、「読み直す」にチェックを入れて解析し直してください。

■ 起動時に Windows の警告が出る場合
署名していないアプリのため、「Windows によって PC が保護されました」と出ることがあります。
「詳細情報」→「実行」で起動できます。

■ 設定と解析結果の保存場所
%APPDATA%\AC6Stamp\
（アンインストールは、このフォルダと AC6Stamp のフォルダを削除するだけです）
