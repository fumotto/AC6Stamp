AC6 Stamp

ARMORED CORE VI の対戦録画から、対戦開始のタイムスタンプと対戦相手の名前を自動で読み取り、YouTubeのコメント欄にそのまま貼れる一覧を作ります。

⬇ ダウンロード（Windows 版）
Windows 10 / 11 ・ 無料

できあがるもの

0:08 vs C4-621 6:42 vs G5 iguaz 13:15 vs V.II Snail

YouTube のコメント欄に貼ると、時刻の部分がリンクになり、各対戦にすぐ飛べるようになります。

使い方

  1. ダウンロードした zip を展開し、AC6Stamp.exe を起動します。
  2. 録画ファイルをウィンドウにドラッグ&ドロップし、「解析開始」を押します。
  3. 終わったら「コピー」を押して、YouTube のコメント欄に貼り付けます。録画と同じフォルダにも 〜_対戦リスト.txt が保存されます。

「自分のパイロット名」を入れておくと、相手の名前だけが一覧に出ます（空欄でも、3試合以上あれば自動で判定します）。

OBS と連携する

録画を止めると、自動で解析が始まるようにできます。アップロード前に一覧ができあがります。

  1. OBS の「ツール」→「スクリプト」を開き、「＋」で zip に入っている ac6stamp_obs.lua を追加します。
  2. 右側の「AC6Stamp.exe の場所」に、展開した AC6Stamp.exe を指定します。
  3. いつも通り録画して停止すると、AC6 Stamp が起動して解析を始めます。

うまく読めないとき

読み取り位置の調整

「読み取り位置の調整…」で録画の1コマを表示し、正しく読めるか確認できます。自動で読めない場合は、名前の位置をマウスで囲んで指定できます。

自分の名前が相手として出る

「自分のパイロット名」の欄に入力してください。「読み直す」のチェックは不要で、すぐに一覧が作り直されます。

起動時に警告が出る

署名していないアプリのため、Windows の警告が出ることがあります。「詳細情報」→「実行」で起動できます。
